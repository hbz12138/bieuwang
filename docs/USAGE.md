# 使用说明

> 这份文档讲"怎么用才不出事"。只想先跑起来，看 [README](../README.md) 的「安装」一节。

---

## 一、四类提醒，什么时候用哪一种

判断标准只有一个：**这件事有没有一个"必须做完"的时刻？**

| 你的情况 | 选 | 它会怎么提醒你 |
|---|---|---|
| 三点开会、八点吃药 | **定时** | 到点响一次；没处理，15 分钟、1 小时后再各追一次 |
| 周五前交材料 | **截止** | 提前 3 天、1 天、2 小时、到点，各响一次（逐级加强） |
| 每周还信用卡、每天浇花 | **重复** | 到点响；这一期没做，**下一期照常**，不会乱 |
| 回个消息、预约体检 | **待办** | 不占时间，进池子；每天 10:00 / 15:00 / 20:00 各抽**一件**问你 |

**最容易用错的是第四种。** 很多人把所有事都设成定时，结果日历被塞满、人被追着跑。判断方法：

> 如果这件事**晚两天做也不会出事**，它就该进**待办池**，不该占一个时间点。

---

## 二、到点之后，你只需要做一个动作

通知弹出时，你面前有三个选择：

- **真在忙** → 点「10 分钟后」或「1 小时后」。定时类会**连日历一起改**，手机也跟着变。
- **今天不想做** → 点「今晚再说」，挪到 20:00。
- **做完了** → 点「完成了」。

不想理它就放着。**它不会消失，会一直在「今天」里变红**，直到你处理掉。

---

## 三、「完成」和「不用了」差在哪

区别是**你为什么会结束它**，不是"删不删"。

| 你点了 | 意思是 | 它去哪 | 长什么样 |
|---|---|---|---|
| **完成** | 我做完了 | 记录 | 标题划线，副标题「已完成 · 今天 15:20」 |
| **不用了** | 这件事我不打算做了 | 记录 | 不划线，副标题「已放弃 · 今天 15:20」 |

**两个都不会真删，都能后悔。**

- 在「记录」里，每行最左边那个圆点就是**恢复**，点一下就回到「今天」。
- 恢复一条早就过期的事，时间会自动顺延到将来，**不会一恢复就标红、立刻响**。
- 真想彻底删掉：点行尾「⋯」→「彻底删除…」，会二次确认。

> 已经结束的事，不会再被「不用了」改写——避免"点了不做了，完成记录里的划线凭空消失"。

## 四、四个分栏分别装什么

```
这件事有时间吗？
├─ 没有 ──────────────────→ 待办池
└─ 有
   ├─ 已经结束（完成/放弃）──→ 记录
   ├─ 是今天，或者已经过期 ──→ 今天（过期的标红）
   └─ 明天及以后 ──────────→ 以后
```

| 分栏 | 内容 | 举例 |
|---|---|---|
| **今天** | 今天到点的 + 已经过期的 | "下午三点开会""上周就该交的材料" |
| **待办池** | **没定时间**的事，靠每天抽问 | "给妈妈回电话""预约体检" |
| **以后** | 明天及以后 | "周五交材料""下周体检" |
| **记录** | 已完成 / 已放弃，都能恢复 | 划线的是做完的，不划线的是放弃的 |

**「今天」里为什么会有过期的？** 故意的。过期的东西如果藏起来，就等于帮你把它忘了——而这是这个工具最不该做的事。所以它进「今天」，并且标红。

## 五、每天只需要 2 分钟

放在你觉得最不容易被打断的时候（建议睡前）。打开面板看一眼：

1. **今天**里变红的，要么做完，要么改时间。**不留隔夜的红色。**
2. **待办池**里挑一件今天能做的，做完再挑下一件。

这两步做完就可以关掉。**别在池子里囤超过 10 件事**——超过这个数，它就从"提醒"变成"压力"，人会自动开始无视它。

---

## 六、把它搬到别的电脑

数据就是一个 JSON 文件，App 就是一个文件夹，两样一起走：

1. 把 `别忘.app` 拷到新电脑的「应用程序」。
2. 把 `reminders.json` 拷到新电脑任意位置。
3. 首次打开时，**数据位置**选到那个文件所在的文件夹。

给别人的话，把 `.dmg` 和他自己的空文件夹给他就行，提醒内容互相独立。

---

## 七、手机上看到它

日历里有**一个单独叫「别忘」的日历**，它挂在你的 iCloud 账户下，会自动出现在 iPhone / iPad 的日历里。

- 想要手机也响：日历 App 里保留这个日历的事件提醒即可。
- 想彻底离线也可以响：设置里「导出 .ics」，导进任何日历 App。

---

## 八、出问题时

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 菜单栏没有图标 | App 没起来 | 应用文件夹里重新双击 |
| 到点没弹通知 | 通知权限被关了 | 系统设置 → 通知 → 别忘 → 允许 |
| 日历里没出现事件 | 日历权限被拒了 | 系统设置 → 隐私与安全性 → 日历 → 勾上别忘 |
| 换电脑后看不到原来的提醒 | 数据位置指错了 | 设置 → 数据位置 → 更改 |
| 想在手机日历里删掉 | 删整个「别忘」日历即可 | 不影响 App 里的数据 |
| 深夜没响 | 默认免打扰 23:00–07:30 | 设置里改「免打扰」 |

---

## 九、它不做什么

- 不联网、没有账号、不收集任何东西。
- 不读你日历里已有的内容，只写自己那个「别忘」日历。
- 电脑睡眠时不响，醒来会补上（在「今天」里变红）。
